🎵 Zingen

Uma landing page inspirada em um aplicativo de karaokê, desenvolvida com HTML5 e CSS3, com foco em uma interface moderna, organizada e totalmente responsiva.

🚀 Sobre o projeto

O Zingen foi criado para praticar conceitos de desenvolvimento front-end, explorando a construção de layouts modernos, responsividade e boas práticas de estruturação utilizando apenas HTML e CSS.

🛠️ Tecnologias:

HTML5
CSS3

✨ Funcionalidades
Interface moderna e intuitiva
Layout totalmente responsivo
Estrutura semântica em HTML
Design inspirado em aplicativos de música e karaokê


📱 Responsividade

A página foi desenvolvida seguindo os princípios de Responsive Web Design, utilizando Media Queries e layouts flexíveis para garantir uma boa experiência em dispositivos móveis, tablets e desktops.
